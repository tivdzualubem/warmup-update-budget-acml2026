# Online Resource 2: Reproducibility package

Article: Separating First-Step Learning-Rate Faults from Scheduler Delay in Adam Training
Journal: Computing
Authors: Tivdzua Lubem Noah; Bader Rasheed; Dmitriy S. Vatolin
Corresponding author: Tivdzua Lubem Noah, Innopolis University, Innopolis, Russia; l.tivdzua@innopolis.university

This package contains code, configurations, retained experimental records, analysis tests and execution logs. Start with README_REPRODUCE.md. The default command performs saved-record analysis and CPU fixtures, not research training. The large predictions and states are available separately as registered in EXTERNAL_EVIDENCE.json. No private correspondence or author-administration records are included. Earlier scientific manuscript snapshots are retained only as deterministic build inputs; manuscript/ contains the current version.
